# 🛰️ Featured Project

## SatQuery AI

**An Agentic Vision-Language Assistant for Multimodal Remote Sensing Image Analysis**

SatQuery is an AI system designed to allow users to interact with satellite imagery using natural language.

### Core capabilities

* 🧠 **Vision-Language Reasoning**
* 🛰️ **Multimodal Remote Sensing**
* ⏳ **Temporal Analysis**
* 🌐 **Optical + SAR Fusion**
* 🎯 **Grounding**
* 🤖 **Agentic AI Architecture**
* 📊 **Geospatial Intelligence**

The project explores how specialized multimodal models can be combined with tools, data pipelines, and reasoning systems to build a more capable remote-sensing assistant.
